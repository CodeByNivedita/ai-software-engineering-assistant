# 🤖 AI Software Engineering Assistant

An AI-powered **multi-agent software engineering assistant** that automates key stages of the software development lifecycle — from understanding requirements to analyzing a codebase, creating an implementation plan, and generating code.

The project uses specialized AI agents, where each agent is responsible for a specific software engineering task.

---

## 📌 Project Overview

Software development often requires developers to manually analyze requirements, understand existing codebases, design implementation plans, and write or modify code.

The **AI Software Engineering Assistant** addresses this by dividing the development workflow into multiple specialized agents.

### Workflow

```text
User Requirement
       ↓
Requirement Analysis Agent
       ↓
Codebase Analyst Agent
       ↓
Coding Planner Agent
       ↓
Coding Agent
       ↓
Generated / Updated Code
```

Each agent receives the relevant output from the previous stage and performs its specialized task.

---

## 🎯 Objectives

* Understand and analyze software requirements automatically.
* Identify functional and technical requirements.
* Analyze an existing codebase and understand its structure.
* Identify relevant files, functions, classes, and dependencies.
* Generate a detailed coding/implementation plan.
* Convert the implementation plan into actual code.
* Reduce repetitive software engineering work.
* Demonstrate how **multi-agent AI systems** can be applied to software development.

## 🧩 Multi-Agent Architecture

### 1. Requirement Analysis Agent

The Requirement Analysis Agent processes the user's software requirement.

**Responsibilities:**

* Understand the user's request.
* Identify the main problem.
* Extract functional requirements.
* Identify constraints and assumptions.
* Convert the requirement into a structured engineering specification.

**Input:**

```text
User's software requirement
```

**Output:**

```text
Structured requirement analysis
```

---

### 2. Codebase Analyst Agent

The Codebase Analyst Agent studies the existing repository.

**Responsibilities:**

* Understand the project structure.
* Identify relevant files.
* Analyze existing functions/classes.
* Identify dependencies.
* Understand existing implementation patterns.
* Determine which parts of the codebase need modification.

**Input:**

```text
Requirement Analysis
+
Existing Codebase
```

**Output:**

```text
Codebase analysis
```

---

### 3. Coding Planner Agent

The Coding Planner Agent converts the requirement and codebase analysis into an implementation plan.

**Responsibilities:**

* Determine the required changes.
* Select files that need modification.
* Define implementation steps.
* Identify new functions/classes when required.
* Consider dependencies and integration.
* Produce an ordered coding plan.

**Input:**

```text
Requirement Analysis
+
Codebase Analysis
```

**Output:**

```text
Detailed Implementation Plan
```

---

### 4. Coding Agent

The Coding Agent implements the plan generated by the Coding Planner.

**Responsibilities:**

* Follow the implementation plan.
* Generate or modify source code.
* Maintain consistency with the existing codebase.
* Implement required functionality.
* Produce the final code changes.

**Input:**

```text
Original Requirement
+
Codebase Analysis
+
Coding Plan
```

**Output:**

```text
Implemented Code
```

## 🔄 Agent Communication

The agents work sequentially.

For example:

```text
Requirement
    ↓
"Add authentication to the application"
    ↓
Requirement Agent
    ↓
Authentication requirements
    ↓
Codebase Analyst
    ↓
Identifies existing user/session modules
    ↓
Coding Planner
    ↓
Creates implementation steps
    ↓
Coding Agent
    ↓
Implements authentication
```

This approach allows each agent to focus on one specialized responsibility rather than asking a single LLM to perform the entire software engineering workflow.

## 💡 Example Use Case

### Input

```text
Add a password reset feature to the existing web application.
Users should be able to request a password reset through their email.
```

### Requirement Agent

Identifies:

* Password reset functionality.
* Email-based verification.
* Secure reset token.
* Password update functionality.

### Codebase Analyst

Identifies:

```text
auth/
├── login.py
├── register.py
└── users.py
```

and determines where the password reset functionality should be integrated.

### Coding Planner

Produces steps such as:

```text
1. Create password reset request endpoint.
2. Generate a secure reset token.
3. Store token with expiration.
4. Send reset email.
5. Create password reset endpoint.
6. Validate token.
7. Update password.
```

### Coding Agent

Implements the planned changes in the appropriate files.
